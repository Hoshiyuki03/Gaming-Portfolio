# Portfolio Update --- Add a Google Drive Projects Link

Make **one small, isolated update** to my existing portfolio.

## What to add

Under the existing **Projects** section, add a short sentence with a
clickable text link to my Google Drive folder containing additional
projects.

Use this wording:

> Want to explore more of my work? **[View More
> Projects](https://drive.google.com/drive/folders/1F1AUmJ3cvNngSyuvyOLHgqsvY8i5bigU)**

Replace `https://drive.google.com/drive/folders/1F1AUmJ3cvNngSyuvyOLHgqsvY8i5bigU` with the Google Drive sharing
link I provide. The words **View More Projects** should be the clickable
link; do not display the long URL.

## Placement and styling

-   Place this sentence neatly below the existing project cards/content,
    within or immediately after the Projects section.
-   Match the portfolio's current typography, spacing, colors, and
    visual style.
-   Keep it subtle, polished, and easy to notice without competing with
    the project cards.
-   Make sure the link works on desktop and mobile.
-   Open the Google Drive link in a new tab and use safe link attributes
    where appropriate (`target="_blank"` and
    `rel="noopener noreferrer"`).

## Strict instructions --- do not change anything else

-   Do **not** redesign, rewrite, reorder, remove, or modify any
    existing project.
-   Do **not** change any existing images, videos, animations,
    transitions, effects, or media links.
-   Do **not** change the navigation, page layout, section order,
    typography, colors, theme, or responsive behavior.
-   Do **not** modify any other portfolio section or component.
-   Do **not** add extra buttons, cards, headings, or promotional
    content.
-   Reuse the existing project section/component and styling conventions
    wherever possible.
-   Keep the code change minimal and limited strictly to adding this one
    linked sentence.

## Completion check

After making the change, verify that: 1. The new sentence appears below
the Projects content. 2. Only **View More Projects** is clickable. 3.
The link opens the supplied Google Drive folder in a new tab. 4. All
existing portfolio content and behavior remain unchanged.
